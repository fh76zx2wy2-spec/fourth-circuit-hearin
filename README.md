# توزيع جلسات الدائرة الرابعة — نسخة GitHub Pages

هذه نسخة مستقلة قابلة للنشر المجاني على GitHub Pages دون Lovable ودون تثبيت Node.js أو شراء رصيد. تتضمن واجهة عربية RTL بألوان وتخطيط قريبين من الموقع الأصلي، ودخول الموظفين، وتوزيع الجلسات، والتواريخ الهجرية والميلادية، ومعاينة صورة التوزيع، وتنزيلها ومشاركتها، وسجل الأيام، والتعويضات، والحفظ عبر **قاعدة Supabase الأصلية**.

## التعديل المطلوب — تم تضمينه

**عند إضافة جلسة جديدة إلى يوم سبق توزيعه، يبقى كل توزيع سابق كما هو حرفيًا.** تسند *الجلسة المضافة فقط* إلى الموظف الأقل تكليفًا في ذلك اليوم، وعند التعادل تُراعى أولوية العجز الأسبوعي. لا يتغير إسناد جلسة قديمة عند زيادة العدد أو إضافة جلسة، ولا عند حذف جلسة أخرى. إعادة توزيع الجميع لا تتم إلا عند الضغط يدويًا على «إعادة التوزيع» والموافقة على التحذير.

## النشر المجاني على GitHub

1. افتح GitHub بحسابك، وأنشئ مستودعًا جديدًا باسم مثل `fourth-circuit-hearings` (اترك مستودع النادي دون تغيير).
2. فك ضغط ملف ZIP. ارفع الملفات والمجلد `assets` إلى **جذر** المستودع، بحيث يكون `index.html` في الجذر؛ لا ترفع ZIP كما هو.
3. افتح `Settings` ← `Pages` ← `Build and deployment`؛ اختر `Deploy from a branch` ثم `main` و`/(root)` ثم `Save`.
4. سيكون رابط المشروع عادةً:

   `https://fh76zx2wy2-spec.github.io/fourth-circuit-hearings/`

5. للتعديل مستقبلًا عدّل الملفات داخل المستودع مباشرة أو ارفع نسخة جديدة منها. النشر مجاني على GitHub Pages للمستودعات العامة ضمن حدود الاستخدام المجاني.

**مهم:** دخول المستخدمين يعتمد على حساباتهم الأصلية في موقع توزيع الجلسات، **وليس** على بريد تسجيل دخول GitHub. لا توجد كلمات مرور مضمّنة في الملفات. المفتاح الموجود في `assets/app.js` مفتاح **publishable** عام؛ لا تضع أي `service_role` في المستودع.

## علاقة هذا الملف بالموقع الأصلي

هذا **إعادة بناء مستقلة** تستند إلى تصميم الموقع ومنطقه، **وليست تصديرًا حرفيًا لجميع ملفات مشروع Lovable**. الوظائف الأساسية متوفرة، لكن يُرجى تجربة النسخة على بيانات اختبار قبل اعتمادها للمحكمة، خصوصًا تسجيل الدخول، والحفظ، وسجلات الاعتذار، والنسخ الاحتياطية. الاتصال بقاعدة البيانات القديمة قائم على صلاحيات Supabase الموجودة؛ لا تُنشئ نسخة قاعدة بيانات ثانية تلقائيًا. التعديلات غير المحفوظة عبر زر «حفظ التوزيع» تبقى محليًا ولا تُعَدّ محفوظة في قاعدة البيانات.

إذا أردت من Claude تعديل **المصدر الأصلي المطابق حرفيًا** بدل هذه النسخة المستقلة، أرسل له ملف `docs/PATCH_ORIGINAL_LOVABLE.md` مع ملفات مشروع Lovable الأصلية.
